# 同花顺PC版优化
同花顺股票软件PC版简单优化批处理。屏蔽同花顺软件启动后开启多个进程。

# 为什么编写此批处理
![同花顺运行时开启非常多的进程](readme_assets/同花顺运行时开启非常多的进程.png)

因为同花顺软件在运行的时候，开启了多个进程程序。即使退出同花顺软件，hxdaemonprocess.exe、updater.exe进程仍然在运行，并且只能通过任务管理器结束。强迫症忍受不了这个，所以写了这个批处理禁止这些额外的进程运行。

# 使用方法
下载`ths_pc_clear.bat`文件到同花顺安装目录（hexin.exe所在目录），运行即可。

# 注意事项
1. 使用批处理后，同花顺多余的进程无法启动，因此可能造成同花顺部分功能不正常。可以用下面的恢复方法恢复批处理所做的修改。
2. 使用批处理后，同花顺无法自动更新。从官网下载最新版同花顺安装程序也会安装失败（因为没有权限覆盖旧程序）。如需更新同花顺请用下面的恢复方法恢复批处理所做的修改后，再更新。
3. 使用批处理后，如果桌面的同花顺快捷方式双击没有反应，请自行新建`hexin.exe`的快捷方式；或修改桌面快捷方式重新指向到`hexin.exe`。因为桌面快捷方式原本指向的`hexinlauncher.exe`已失效。
4. `HxExternal.exe`进程用于同花顺软件内点击资讯标签显示网页内容。如不需要此功能，可自行修改批处理将`HxExternal.exe`一并屏蔽。

# 恢复方法
1. 同花顺安装目录上点右键，选“属性”。
2. 切换到“安全”选项卡。点“高级”按钮。
3. 对话框最下方的“使用可从此对象继承的权限项目替换所有子对象的权限项目”打钩，点“确定”按钮。
4. 等进度对话框走完，关闭属性对话框即可。
